# GTA V — Ajuste visual de consumíveis do mod de zumbis

Código-fonte de um script para ScriptHookVDotNet que exibe objetos de água e comida durante o uso de consumíveis. O arquivo `ZombiesModFixConsumibles.cs` é a única parte deste projeto preparada para publicação.

O script depende de GTA V, ScriptHookVDotNet e do mod de zumbis instalados separadamente. Este repositório não contém o jogo, o mod de zumbis, seus DLLs, saves ou backups.
